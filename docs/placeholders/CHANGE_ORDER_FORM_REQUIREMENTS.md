Temporary placeholder for the signed Change Order form template.

Until the approved form is supplied, use Northgate HQ branding and the current Change Order
fields: job, owner/contractor, CO number, title, description, date, price, internal cost,
budget division allocations, signature/acceptance blocks, and attachment reference.

Replace this file with the approved layout, legal language, signature requirements, and any
owner-specific wording before finalizing the downloadable document generator.
